# 00. 项目概述

## 1. 背景

学习一门新知识（技术栈、学科、开源项目、公司内部系统……）时，最耗时的往往不是"读材料"本身，而是：

- 从一堆分散的资料（PDF 讲义、Word 文档、PPT 课件、Excel 表格、在线文档站、GitHub 仓库）里**找到并整合**知识；
- 规划一个**合理的学习路径**，而不是从头到尾线性啃完所有材料；
- 通过**提问、做题、被讲解**来检验和巩固理解，而不是"看完就忘"。

现有工具通常只解决其中一部分：

- **RAG 问答类工具**（AnythingLLM、Quivr、RAGFlow、Danswer/Onyx）解决"基于资料问答"，但缺少学习计划、题库、系统讲解等**教学场景能力**；
- **AI 助教类项目**（如 EduAgent、OpenTutor）已经在做"资料 → 学习计划/题库/讲解"，但对**代码仓库（GitHub repo）**这种资料源的支持较弱，也较少针对"技术学习"场景优化。

本项目的目标，是做一个**以教学场景为核心的学习 Agent**：用户上传/提供任意资料源，Agent 以这些资料为**唯一或主要依据**，提供问答、学习计划、题库、系统讲解、Lecture 式讲课等一整套学习支持能力。

## 2. 项目目标

做一个可以「喂给它任何资料，就能围绕这些资料辅导你学习」的通用学习 Agent，具体包含：

1. **多源资料摄取**：文档（PDF/Word/PPT/Excel/Markdown）、任意网址/文档站点、GitHub 仓库链接。
2. **忠实于资料的问答**：回答必须可追溯到具体资料片段（引用来源），减少幻觉。
3. **学习计划生成**：根据资料体量、用户目标（考试时间、每日可投入时长、当前水平）生成分阶段学习计划。
4. **题库生成与测验**：自动生成选择题/填空/简答/编程题，支持练习、测验、错题本、间隔重复复习。
5. **系统讲解**：按知识点依赖关系，教科书式地讲解整套资料的知识体系（可生成大纲/知识图谱）。
6. **Lecture 模式**：以"讲课"的形式主动、分节地讲授内容，并在讲解中穿插提问、检验理解（苏格拉底式互动）。
7. **按需联网检索补充资料**：当用户**主动要求**时，Agent 可以联网搜索并把检索到的网页内容作为新的资料源纳入学习空间，用于补足现有资料的空白（默认关闭，绝不自动触发）。

## 3. 目标用户

- **自学者 / 学生**：备考、自学某学科，手上有讲义/教材/课件。
- **工程师 / 新人 onboarding**：需要快速理解一个新的代码仓库或内部技术文档站。
- **培训 / 内容创作者**（远期）：把自己的资料包装成课程供学员学习。

MVP 阶段先聚焦前两类用户（个人自学 + 技术资料学习），因为这两类用户的资料形态覆盖了 PDF/Word/PPT/Excel + 网址 + GitHub repo 全部四种输入类型。

## 4. 核心价值主张

> "上传你的资料，我把它变成一门可以问、可以练、可以听讲的课。"

区别于通用 ChatGPT/Claude 直接问答的地方：

- **资料是第一性的（grounded）**：所有输出（问答/计划/题库/讲解）都要能追溯到具体资料来源，而不是模型的通用知识；当资料不足以回答时应明确告知，而非编造。
- **教学产物是结构化的**：不是一次性聊天回复，而是持久化的学习计划、题库、讲义，可以被追踪进度、反复复习。
- **支持"资料"这一独特输入源**：这是与通用 RAG 工具（AnythingLLM 等）最大的差异点——需要对代码仓库做专门的摄取和讲解（理解目录结构、模块依赖、核心流程），而不仅仅是把代码当文本切块。

## 5. 非目标（Out of Scope，至少 MVP 阶段）

- 不做多人协作/课堂管理（教师建课、学生加入班级等 To B 教育 SaaS 能力）——远期可考虑。
- 不做语音/视频讲课（TTS/数字人讲课）——远期可考虑，架构上预留扩展点即可。
- 不做完全离线/私有化部署的强制要求，但架构上应支持通过配置切换到本地模型（Ollama 等），不绑定单一 LLM 供应商。
- 不做通用搜索引擎式的开放域问答——超出资料范围的问题**默认**应有明确的"资料未覆盖"提示，而不是自由发挥（可配置是否允许"结合通用知识补充"）。

  这里需要与"按需联网检索"（目标 7）区分清楚：联网检索**只在用户明确要求时触发**（点击"联网补充资料"按钮或明确说"去网上查一下"），检索结果会作为**带出处的资料源**进入学习空间，同样受"可溯源"约束；而不是让 Agent 在每次答不上来时自动上网搜索——后者会让"资料是第一性的"这一核心价值主张失效，用户将无法分辨答案来自自己的资料还是来自互联网的任意内容。
